Top Recommendation: LLMLingua-2 (by Microsoft)This is the most "battle-tested" repository on GitHub for prompt compression. Unlike older rule-based compressors, LLMLingua-2 uses a small, high-speed model to identify and remove redundant tokens without losing the "reasoning backbone" of your prompt.GitHub: microsoft/LLMLinguaWhy it fits your setup:For Haiku 4.5: It can compress prompts by 3x–5x before they ever hit the API. This significantly reduces the "Time to First Token" (TTFT), making your live showreel feel even more instantaneous.For Sonnet 4.6: It includes a "Question-Aware" mode. If your governance agent is looking for a specific policy violation, the optimizer will preserve every token relevant to that specific query while stripping the "fluff" from massive policy PDFs.2. Best for Complex Agents: Context-OptimizerIf your agents are running in a "long-running session" (typical for file managers and governance bots), this repo is specifically built to handle the "sliding window" problem.GitHub: roymaste/context-optimizerUnique Feature: Hot/Cold Memory Switching. It automatically moves "solved" governance tasks or processed file chunks into a "Cold" vector layer and keeps only the active logic and most recent decisions in the "Hot" context (the tokens you pay for).Best for: Your Sonnet 4.6 agents. It prevents the context window from bloating over time, which is critical when Sonnet is doing heavy reasoning over deep directory structures.3. Anthropic models (Haiku/Sonnet) are natively trained to handle data wrapped in XML tags (e.g., <file_content>).
